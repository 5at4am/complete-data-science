# Model Deployment Engineer

Owns the path from a trained model to a running service. Optimizes inference speed, low-latency serving, and model lifecycle rollout.

## What They Do
- Serve trained models in production (REST/gRPC/streaming)
- Optimize inference: quantization, pruning, batching, caching
- Manage model versions, rollouts, and rollbacks
- Set up canary and shadow deployments
- Integrate models into existing application backends
- Benchmark latency, throughput, and cost

## Key Skills
- Docker, Kubernetes, FastAPI, Triton/ONNX/TensorRT
- Model optimization: quantization (4-bit/8-bit), distillation
- Deployment patterns: canary, A/B, shadow traffic
- Monitoring and alerting for model services
- Stream processing for real-time scoring

## Core Tools
Docker, Kubernetes, Triton Inference Server, ONNX, TensorRT, FastAPI, MLflow

## Career Growth
- Model Deployment Engineer → ML Platform Engineer → Staff Infra

## Salary (US, 2026)
- $130K–$210K+ depending on scale

## Who It Suits
Backend/DevOps engineers who like the deployment edge of ML — fast serving, cost optimization, and reliable rollout mechanics.
