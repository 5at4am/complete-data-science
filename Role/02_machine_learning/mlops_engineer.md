# MLOps Engineer

Manages the lifecycle of ML models in production — deployment, monitoring, retraining pipelines, experiment tracking, and compute cost optimization. "DevOps for AI."

## What They Do
- Build automated training/testing/deployment pipelines (CI/CD for ML)
- Model versioning, registry, and reproducibility
- Monitoring: drift detection, performance decay, data quality
- Retraining and re-deployment workflows
- Manage compute and GPU infrastructure costs
- Feature stores (Feast, Tecton)

## Key Skills
- Kubernetes, Kubeflow, MLflow 2.x, Argo Workflows
- Weights & Biases, experiment tracking
- Docker, CI/CD (GitHub Actions, GitLab CI)
- Cloud platforms (AWS/GCP/Azure)
- Monitoring/observability stack

## Core Tools
Kubernetes, Kubeflow, MLflow, W&B, Argo Workflows, Feast, Tecton

## Career Growth
- MLOps Engineer → ML Platform Engineer → Staff Infra Engineer → Head of ML Platform
- Exits: DevOps/Platform/SRE lanes

## Salary (US, 2026)
- Entry: $100K–$130K
- Mid: $130K–$180K
- Senior: $160K–$220K
