# Machine Learning Engineer

Builds, trains, and deploys ML models from data to production. The "stable anchor" of the ML field — actually trains models from scratch, unlike AI Engineers who call pretrained APIs.

## What They Do
- Design and train ML models (supervised/unsupervised, deep learning)
- Feature engineering and training pipelines
- Deploy, serve, and monitor models in production
- Optimize model performance, latency, and cost
- Build and maintain model lifecycle tooling

## Key Skills
- Python; PyTorch, TensorFlow, XGBoost, LightGBM
- Software engineering: Docker, Kubernetes, APIs
- Model training, deployment, evaluation, monitoring
- MLflow, Kubeflow, feature stores
- Cloud: AWS SageMaker, GCP Vertex AI, Azure ML

## Core Tools
PyTorch 2.5+, TensorFlow, Hugging Face Transformers, Ray, vLLM, Triton Inference Server, Docker, Kubernetes

## Career Growth
- ML Engineer → Senior → Staff/Principal → ML Platform Engineer → Head of ML Engineering

## Salary (US, 2026)
- Entry: $110K–$145K
- Mid: $150K–$200K
- Senior: $200K–$270K
- Principal/Staff: $280K–$400K+
- Median total comp (Levels.fyi): ~$265K; FAANG-tier crosses $300K+

## Who It Suits
Systems thinkers with strong coding instincts. If you care about APIs, reliability, scale, automation, versioning, testing, and monitoring, this is your path. Demand: High and growing.
