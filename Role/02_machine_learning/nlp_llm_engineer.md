# NLP / LLM Engineer

Builds systems that process and understand human language — chatbots, search, text classification, sentiment, translation, and large language model applications.

## What They Do
- Process and model text data (tokenization, embeddings, transformers)
- Fine-tune foundation models (LoRA, QLoRA, full fine-tuning)
- Build RAG systems and information retrieval
- Prompt engineering and evaluation harnesses
- Optimize context management, latency, and cost

## Key Skills
- Hugging Face Transformers, spaCy, PyTorch
- Embeddings, vector databases
- LangChain, LlamaIndex, DSPy
- Eval frameworks: Ragas, Braintrust, LangSmith
- Fine-tuning: LoRA, QLoRA; inference: vLLM, quantized serving

## Core Tools
Hugging Face, PyTorch, spaCy, vLLM, LangChain, vector DBs (Pinecone, Weaviate, pgvector)

## Salary (US, 2026)
- Mid: $160K–$210K
- Senior: $210K–$320K
- Staff/Principal: $300K–$450K base

## Career Growth
- NLP Engineer → LLM Engineer → Senior LLM Engineer → Staff/Principal
- Frontier labs (Anthropic, OpenAI, Cohere, Databricks) pay a real premium here

## Who It Suits
MS in CS or linguistics with strong language-data interest. One of the few titles where the specialization premium is genuinely justified.
