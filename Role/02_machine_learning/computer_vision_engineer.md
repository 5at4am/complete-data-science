# Computer Vision Engineer

Builds systems that interpret visual information from images and video — object detection, segmentation, facial recognition, medical imaging, autonomous vehicle perception, quality inspection.

## What They Do
- Collect and label image/video data
- Train and fine-tune vision models (CNNs, ViTs, YOLO)
- Evaluate model accuracy and robustness
- Optimize inference speed for real-time applications
- Deploy to edge/embedded or cloud

## Key Skills
- OpenCV, PyTorch, TensorFlow, Keras
- Image processing and augmentation
- Object detection/segmentation architectures (YOLO, Mask R-CNN, ViT)
- Model optimization (ONNX, TensorRT)
- Python/C++

## Core Tools
OpenCV, PyTorch, TensorFlow, ONNX, TensorRT

## Career Growth
- CV Engineer → Senior CV Engineer → CV Research Scientist
- Domain exits: autonomous vehicles, medical imaging, AR/VR

## Salary (US, 2026)
- Mid: $140K–$230K (varies by industry)

## Who It Suits
ML/robotics/CS backgrounds drawn to visual data — cameras, drones, medical scans, autonomous systems.
