# AI Engineer

Builds AI-powered application features primarily using pretrained models via API. The default general-purpose title for production LLM work in 2026 — LinkedIn's "fastest-growing role in the US."

## What They Do
- Integrate LLM APIs into production products
- Design and ship RAG pipelines
- Write evaluations and guardrails
- Own agentic flows end-to-end
- Manage cost, latency, and quality of AI features
- Build full-stack AI applications (Python/TypeScript)

## Key Skills
- Python, TypeScript
- OpenAI/Anthropic/Gemini APIs
- LangChain, LlamaIndex, LangGraph, DSPy
- Vector DBs (Pinecone, Weaviate, pgvector)
- Evals: LangSmith, Braintrust, Ragas
- Docker, cloud deployment
- Observability, CI/CD

## Core Tools
Python, TypeScript, LLM APIs, LangChain/LlamaIndex, vector DBs, LangSmith/Braintrust, Docker, AWS/GCP

## Career Growth
- AI Engineer → Senior → Staff → Principal → AI Architect / AI Tech Lead
- Fastest-growing ladder in the field

## Salary (US, 2026)
- Entry: $110K–$140K base
- Mid: $160K–$220K
- Senior: $180K–$250K base
- Levels.fyi median: $159K ("AI Engineer"); $245K ("AI Software Engineer")

## Who It Suits
Software engineers who want to build AI products — especially LLM apps, agents, and retrieval systems — without becoming pure research scientists. Prefers APIs/backend over math derivation.
