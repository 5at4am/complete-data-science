# RAG / Context Engineer

Designs the full context envelope around LLM calls: retrieval, memory, tool definitions, system prompts, metadata, and governance — so agents behave reliably.

## What They Do
- Design retrieval pipelines (chunking, embedding, reranking)
- Build memory systems and knowledge bases
- Define tool schemas and system prompts for agents
- Evaluate context drift and retrieval quality
- Govern the data injected into agents
- Maintain reusable "context packs" for business logic

## Key Skills
- Information retrieval fundamentals (BM25, dense retrieval, reranking)
- Vector databases and embeddings
- LangChain, LlamaIndex, DSPy, LangGraph
- RAG evaluation (Ragas-style): faithfulness, answer relevance, retrieval hit rate
- System/prompt design

## Core Tools
Vector DBs (Pinecone, Weaviate, pgvector), LangChain, LlamaIndex, DSPy, vLLM
