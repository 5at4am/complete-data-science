# Agent Engineer / Agentic AI Engineer

Designs autonomous multi-agent systems where LLMs orchestrate tool use, make decisions, and chain complex actions across multi-step workflows.

## What They Do
- Architect multi-agent systems (planner, executor, verifier, registry)
- Define tool/function calling interfaces
- Build memory, state, and human-in-the-loop loops
- Design planning and reflection loops
- Evaluate reliability, token cost, and failure recovery
- Ship end-to-end autonomous workflows

## Key Skills
- LangGraph, AutoGen, CrewAI (or custom orchestration)
- Tool use, function calling, structured outputs
- State machines + agent memory patterns
- Observability of long-running agent traces
- Evaluation of multi-step task success

## Core Tools
LangGraph, Docker, vector DBs, LLM APIs, agent observability stack

## Career Growth
- Agent Engineer → Senior → Agent Architect → Staff
- Newest specialized AI title; demand growing fast with agentic product hype

## Salary (US, 2026)
- Tracks AI Engineer bands: $150K–$300K+ depending on seniority

## Who It Suits
Full-stack + LLM developers who love autonomous systems design, planning, and tool orchestration. Think "building the AI that plans and executes work, not just answers questions."
