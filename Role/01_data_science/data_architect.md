# Data Architect

Designs and manages the overall data architecture of an organization — ensuring data is structured, secure, scalable, and governance-ready.

## What They Do
- Design data systems, warehouses, lakes, and data models
- Define data integration and quality standards
- Set data governance, security, and compliance policies
- Evaluate data platform technologies (Snowflake, Databricks, Iceberg)
- Map data flows across the enterprise
- Mentor engineering teams on architecture decisions

## Key Skills
- Data modeling (relational, dimensional, Data Vault)
- SQL/NoSQL, data warehousing, data lakehouse
- Cloud platforms (AWS/GCP/Azure)
- Data integration, streaming, and governance
- Big systems thinking and standardization

## Core Tools
Snowflake, BigQuery, Databricks, dbt, Kafka, Terraform, ERWin/Lucidchart-style modeling tools

## Career Growth
- Data Engineer → Senior → Data Architect → Enterprise Data Architect / Head of Data Infrastructure

## Salary (US, 2026)
- $140K–$240K+ depending on seniority and scale

## Who It Suits
Senior data engineers who prefer owning the shape of the whole system over building any single pipeline.
