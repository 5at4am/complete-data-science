# Analytics Engineer

Owns the transformation layer — turns raw data into clean, tested datasets that analysts and scientists can trust. The highest-leverage entry point in 2026 because clean semantic layers are what every GenAI assistant depends on.

## What They Do
- Model and transform data using dbt
- Define business logic and consistent metrics
- Ensure data quality with tests and documentation
- Sit between data engineering and data analysis

## Key Skills
- SQL, dbt (core), Git
- Data modeling (star/snowflake schemas)
- Warehouses: Snowflake, BigQuery, Databricks
- Increasingly Apache Iceberg

## Core Tools
dbt, SQL, Snowflake, BigQuery, Git, Iceberg

## Salary (US, 2026)
- Median base: ~$135K

## Career Growth
- Analytics Engineer → Senior Analytics Engineer → Analytics Manager → Head of Data
- Often the stepping stone into Data/Science tracks

## Who It Suits
People who like building clean, reliable data products rather than doing analysis themselves — the "builder" of the analysis world.
