# Data Scientist

Extracts insights from data and builds predictive models to support business decisions. Sits closer to the business problem than infrastructure — output is a prediction, recommendation, or tested hypothesis.

## What They Do
- Run experiments (A/B testing) and statistical analysis
- Build predictive models on structured datasets
- Design experiments and translate uncertainty into decisions
- Communicate findings to stakeholders
- LLM evaluation and applied NLP increasingly in scope

## Key Skills
- Python (Pandas, NumPy, scikit-learn), R
- SQL (the single largest differentiator vs ML/AI engineers)
- Statistics, probability, hypothesis testing
- Causal inference (DoWhy, EconML), experimentation platforms (Eppo, Statsig)
- Machine learning fundamentals, data visualization
- Communication and storytelling

## The Three Lanes (2026)
1. **Product / Decision Science** — experiments, causal inference, metrics. Fastest promotions, business-visible.
2. **Model / Production Science** — churn, forecasting, fraud, monitoring. Overlaps ML Engineer.
3. **Research Science** — novel methods, published work, PhD track.

## Core Tools
Python, R, SQL, scikit-learn, PyTorch, Spark, Snowflake/BigQuery

## Career Growth
- Data Scientist I → II → Senior → Staff/Principal → Head of Data Science → Chief Data Officer
- Exits: MLE (production), Decision Scientist (leadership-bound), Data Engineer

## Salary (US, 2026)
- Entry: $90K–$120K
- Mid: $130K–$175K
- Senior: $175K–$230K
- Staff/Principal: $230K–$320K+
- Median (BLS): $112,590

## Who It Suits
People drawn to math, statistics, and experimentation who want to model data and test hypotheses. Specialization (NLP, CV, time series, causal) now beats generalist.
