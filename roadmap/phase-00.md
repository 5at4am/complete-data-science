# Phase 00 — Environment Setup

> **Goal:** Get a working, verified environment so all future learning is frictionless.

**Prerequisites:** None
**Duration:** Short (setup + verification)
**Mastery target:** Level 3 (independent implementation of environment tasks)

---

## Units

### Unit 00.1 — Environment Verification
- **Purpose:** Confirm Python, packages, GPU, and internet all work.
- **Implementation:** Run the environment-verification notebook.
- **Outcome:** A verified, reproducible environment.
- **Notebook:** `notebooks/00_environment/00_environment_verification.ipynb`

### Unit 00.2 — Jupyter Workflow
- **Purpose:** Learn to use Jupyter effectively (cells, kernels, markdown, magic commands).
- **Implementation:** Practice notebook operations.
- **Outcome:** Comfortable with the notebook interface.

### Unit 00.3 — Git & Version Control
- **Purpose:** Learn Git basics for tracking work and recovering from mistakes.
- **Implementation:** Init repo, commit, branch, merge.
- **Outcome:** Can version-control all work.

### Unit 00.4 — Python Environments & Packages
- **Purpose:** Understand environments, dependencies, and package management.
- **Implementation:** Create/use venvs, install packages.
- **Outcome:** Can set up any environment.

---

## Phase Review

- [ ] Environment verification passes
- [ ] Jupyter workflow comfortable
- [ ] Git basics mastered
- [ ] Environment management understood

## Mastery Check

At the end of this phase, you should be able to:
1. Verify your environment is working.
2. Create a new notebook and run it.
3. Initialize a Git repo and commit work.
4. Set up a Python environment from scratch.
