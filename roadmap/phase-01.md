# Phase 01 — Python Foundations

> **Goal:** Build a solid Python foundation for data work, including NumPy, Pandas, and visualization.

**Prerequisites:** Phase 00
**Mastery target:** Level 5 (core concepts)

---

## Units

### Unit 01.1 — Python Basics
- Variables, data types, operators
- Control flow (if/else, loops)
- **Implementation:** Small programs
- **Outcome:** Write basic Python

### Unit 01.2 — Data Structures
- Lists, tuples, dicts, sets
- Comprehensions
- **Implementation:** Manipulate data structures
- **Outcome:** Choose the right structure

### Unit 01.3 — Functions & Scope
- Function definition, parameters, return values
- Scope, closures
- **Implementation:** Write reusable functions
- **Outcome:** Modular code

### Unit 01.4 — Object-Oriented Programming
- Classes, objects, methods
- Inheritance, encapsulation
- **Implementation:** Build a small class hierarchy
- **Outcome:** Understand OOP for ML code

### Unit 01.5 — NumPy Fundamentals
- Arrays, shapes, broadcasting
- Vectorized operations
- **Implementation:** NumPy array operations
- **Outcome:** Efficient numerical computing

### Unit 01.6 — Pandas Fundamentals
- Series, DataFrames
- Indexing, filtering, groupby
- **Implementation:** Data manipulation
- **Outcome:** Work with tabular data

### Unit 01.7 — Matplotlib & Visualization
- Line, scatter, bar, histogram plots
- Subplots, styling
- **Implementation:** Visualize data
- **Outcome:** Communicate data visually

### Unit 01.8 — File I/O & Error Handling
- Reading/writing files
- try/except, exceptions
- **Implementation:** Robust file handling
- **Outcome:** Handle errors gracefully

### Unit 01.9 — Python for Data Work (Synthesis)
- Cumulative review
- Mini project: data processing pipeline
- **Outcome:** Combine all Python skills

## Mastery Check

At the end of this phase, you should be able to:
1. Write Python to process data independently.
2. Use NumPy for vectorized computation.
3. Use Pandas for tabular data.
4. Visualize data with Matplotlib.
5. Handle errors and files robustly.
