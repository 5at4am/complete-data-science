# Phase 11 — RAG

> **Goal:** Master Retrieval-Augmented Generation — from keyword search to agentic RAG.

**Prerequisites:** Phase 09, Phase 10
**Mastery target:** Level 5 (core concepts)

---

## Units

### Unit 11.1 — Why RAG Exists
- LLM limitations, knowledge cutoff, hallucination
- **Implementation:** Demonstrate the problem
- **Outcome:** Understand the motivation

### Unit 11.2 — Keyword Search
- BM25, TF-IDF search
- **Implementation:** Build keyword search
- **Outcome:** Baseline retrieval

### Unit 11.3 — Embeddings
- Text → vectors, semantic similarity
- **Implementation:** Generate embeddings
- **Outcome:** Semantic representation

### Unit 11.4 — Vector Similarity
- Cosine, dot product, Euclidean
- **Implementation:** Compute similarity
- **Outcome:** Understand vector search

### Unit 11.5 — Vector Databases
- Chroma, FAISS
- **Implementation:** Store and search vectors
- **Outcome:** Use vector databases

### Unit 11.6 — Document Ingestion
- Load documents (PDF, text, web)
- **Implementation:** Ingest documents
- **Outcome:** Handle real documents

### Unit 11.7 — Chunking
- Chunk size, overlap, strategies
- **Implementation:** Chunk documents
- **Outcome:** Chunk effectively

### Unit 11.8 — Embedding Generation
- Generate embeddings for chunks
- **Implementation:** Embed a corpus
- **Outcome:** Build the index

### Unit 11.9 — Retrieval
- Query → retrieve relevant chunks
- **Implementation:** Retrieve
- **Outcome:** Get relevant context

### Unit 11.10 — Reranking
- Improve retrieval with reranking
- **Implementation:** Rerank results
- **Outcome:** Better retrieval

### Unit 11.11 — Context Construction
- Build the prompt context
- **Implementation:** Construct context
- **Outcome:** Ground the generation

### Unit 11.12 — Generation & Grounding
- Generate answers grounded in context
- **Implementation:** Full RAG pipeline
- **Outcome:** Grounded answers

### Unit 11.13 — RAG Evaluation
- Context precision/recall, groundedness, faithfulness
- **Implementation:** Evaluate RAG
- **Outcome:** Measure RAG quality

### Unit 11.14 — Naive RAG (Build)
- Build a complete naive RAG system
- **Implementation:** End-to-end RAG
- **Outcome:** Working RAG system

### Unit 11.15 — Advanced RAG
- Hybrid search, metadata filtering, multi-query, parent-child
- **Implementation:** Advanced RAG
- **Outcome:** Better retrieval

### Unit 11.16 — Agentic RAG
- Agent decides when/how to retrieve
- **Implementation:** Agentic RAG
- **Outcome:** Adaptive retrieval

### Unit 11.17 — RAG Synthesis & Review
- Cumulative review
- Mini project: RAG application
- **Outcome:** Apply RAG independently
