# Phase 14 — AI Agents

> **Goal:** Master AI agents — from tool calling to multi-agent systems, including failure modes and security.

**Prerequisites:** Phase 12, Phase 13
**Mastery target:** Level 5 (core concepts)

- **Outcome:** Understand the agent loop

### Unit 14.3 — Planning

- **Implementation:** Add planning
- **Outcome:** Multi-step reasoning

### Unit 14.4 — Execution

- **Implementation:** Stateful agent

### Unit 14.9 — Multi-Agent Systems

- **Implementation:** Multi-agent system
