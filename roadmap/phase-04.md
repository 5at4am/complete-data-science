# Phase 04 — Data Analysis & Preparation

> **Goal:** Learn to explore, clean, and prepare data for machine learning — including the critical topic of data leakage.

**Prerequisites:** Phase 01, Phase 03
**Mastery target:** Level 5 (core concepts)

---

## Units

### Unit 04.1 — Data Exploration & EDA
- Summary statistics, distributions, correlations
- **Implementation:** Full EDA on a dataset
- **Outcome:** Understand data before modeling

### Unit 04.2 — Data Cleaning
- Inconsistent formats, duplicates, typos
- **Implementation:** Clean a messy dataset
- **Outcome:** Prepare clean data

### Unit 04.3 — Missing Values
- Types of missingness (MCAR, MAR, MNAR)
- Imputation strategies
- **Implementation:** Handle missing data
- **Outcome:** Deal with missing values properly

### Unit 04.4 — Outliers
- Detection methods (IQR, z-score, visualization)
- **Implementation:** Detect and handle outliers
- **Outcome:** Understand outlier impact

### Unit 04.5 — Feature Scaling & Encoding
- Standardization vs normalization
- One-hot, label, target encoding
- **Implementation:** Scale and encode features
- **Outcome:** Prepare features for models

### Unit 04.6 — Train/Validation/Test Splits
- Proper splitting strategies
- **Implementation:** Split data correctly
- **Outcome:** Avoid evaluation errors

### Unit 04.7 — Data Leakage (CRITICAL)
- What it is, why it's dangerous
- Scaling before splitting, target leakage
- **Implementation:** Demonstrate leakage
- **Outcome:** Recognize and prevent leakage

### Unit 04.8 — Data Preparation Synthesis & Review
- Cumulative review
- Mini project: full data pipeline
- **Outcome:** Prepare data end-to-end

---

## Mastery Check

At the end of this phase, you should be able to:
1. Explore and understand any dataset.
2. Clean messy data.
3. Handle missing values and outliers.
4. Scale and encode features correctly.
5. Split data without leakage.
6. Recognize data leakage in any pipeline.
