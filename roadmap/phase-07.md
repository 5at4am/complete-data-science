# Phase 07 — NLP

> **Goal:** Master natural language processing — from text preprocessing to embeddings and sequence models.

**Prerequisites:** Phase 05, Phase 06
**Mastery target:** Level 5 (core concepts)

---

## Units

### Unit 07.1 — Text Preprocessing & Tokenization
- Tokenization, normalization, stemming, lemmatization
- **Implementation:** Preprocess text
- **Outcome:** Clean text data

### Unit 07.2 — Bag of Words & TF-IDF
- BoW, TF-IDF, sparse representations
- **Implementation:** Build BoW and TF-IDF
- **Outcome:** Represent text numerically

### Unit 07.3 — N-grams
- Unigrams, bigrams, trigrams
- **Implementation:** Build n-gram features
- **Outcome:** Capture local context

### Unit 07.4 — Text Classification
- Classify text with classical ML
- **Implementation:** Spam/sentiment classifier
- **Outcome:** Apply ML to text

### Unit 07.5 — Word Embeddings (Word2Vec concepts)
- Dense vectors, similarity, Word2Vec
- **Implementation:** Explore embeddings
- **Outcome:** Understand semantic representation

### Unit 07.6 — Sequence Models for NLP
- RNN/LSTM for text
- **Implementation:** Sequence model for text
- **Outcome:** Model text sequences

### Unit 07.7 — Attention for NLP
- Attention in sequence models
- **Implementation:** Attention for text
- **Outcome:** Foundation for transformers

### Unit 07.8 — NLP Evaluation
- Accuracy, F1, BLEU, ROUGE
- **Implementation:** Evaluate NLP models
- **Outcome:** Measure NLP quality

### Unit 07.9 — NLP Synthesis & Review
- Cumulative review
- Mini project: NLP application
- **Outcome:** Apply NLP independently

---

## Mastery Check

At the end of this phase, you should be able to:
1. Preprocess and tokenize text.
2. Build BoW/TF-IDF representations.
3. Classify text with ML.
4. Understand word embeddings.
5. Build sequence models for text.
6. Evaluate NLP models.
