# Phase 08 — Transformers

> **Goal:** Master the transformer architecture — the foundation of modern NLP and LLMs.

**Prerequisites:** Phase 06, Phase 07
**Mastery target:** Level 5 (core concepts)

---

## Units

### Unit 08.1 — Transformer Architecture (from scratch)
- Encoder, decoder, self-attention, feed-forward
- **Implementation:** Build a transformer from scratch
- **Outcome:** Understand the architecture deeply

### Unit 08.2 — Self-Attention Deep Dive
- Query, key, value, scaled dot-product attention
- Multi-head attention
- **Implementation:** Implement self-attention
- **Outcome:** Understand attention mechanics

### Unit 08.3 — Positional Encoding
- Why position matters, sinusoidal encoding
- **Implementation:** Implement positional encoding
- **Outcome:** Handle sequence order

### Unit 08.4 — Encoder-Decoder Architecture
- Encoder-decoder for seq2seq
- **Implementation:** Build encoder-decoder
- **Outcome:** Understand translation-style tasks

### Unit 08.5 — BERT-style Models
- Encoder-only, bidirectional, masked LM
- **Implementation:** Use BERT
- **Outcome:** Understanding tasks

### Unit 08.6 — Causal Language Models (GPT-style)
- Decoder-only, causal attention, next-token prediction
- **Implementation:** Use a GPT-style model
- **Outcome:** Generation tasks

### Unit 08.7 — Tokenizers (BPE, WordPiece)
- Subword tokenization
- **Implementation:** Use tokenizers
- **Outcome:** Understand tokenization

### Unit 08.8 — Hugging Face Ecosystem
- Transformers, Datasets, Tokenizers libraries
- **Implementation:** Use HF pipelines
- **Outcome:** Leverage the ecosystem

### Unit 08.9 — Fine-tuning Transformers
- Fine-tune for classification, QA, generation
- **Implementation:** Fine-tune a model
- **Outcome:** Adapt models to tasks

### Unit 08.10 — Transformers Synthesis & Review
- Cumulative review
- Mini project: transformer application
- **Outcome:** Apply transformers independently
