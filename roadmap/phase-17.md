# Phase 17 — Capstone Engineering

> **Goal:** Complete capstones that require architectural decisions and independent engineering.

**Prerequisites:** All phases
**Mastery target:** Level 6 (teaching)

---

## Capstones

### Unit 17.1 — ML Capstone
- End-to-end predictive system
- **Level:** 4 (engineering challenge)
- **Requirements:** data pipeline, model, evaluation, API
- **Outcome:** Build a complete ML system

### Unit 17.2 — Deep Learning Capstone
- Train and evaluate a neural model
- **Level:** 4
- **Requirements:** architecture, training, evaluation
- **Outcome:** Build a complete DL system

### Unit 17.3 — NLP Capstone
- Build an NLP application
- **Level:** 4
- **Requirements:** preprocessing, model, evaluation
- **Outcome:** Build a complete NLP system

### Unit 17.4 — RAG Capstone
- Build a production-style RAG system
- **Level:** 5 (production-style)
- **Requirements:** ingestion, retrieval, generation, evaluation
- **Outcome:** Build a complete RAG system

### Unit 17.5 — Agent Capstone
- Build a stateful tool-using agent
- **Level:** 5
- **Requirements:** tools, planning, memory, evaluation
- **Outcome:** Build a complete agent system

### Unit 17.6 — Final AI Engineering Capstone
- Combine everything
- **Level:** 5
- **Requirements:**
  - data
  - model
  - LLM
  - RAG
  - tools
  - agent
  - evaluation
  - API
  - frontend/backend
  - deployment
  - monitoring
  - security
  - documentation
- **Outcome:** Independently design and build a new AI/ML system

---

## Capstone Requirements

Every substantial project must contain:

- [ ] Problem definition
- [ ] Business/real-world context
- [ ] Requirements
- [ ] Constraints
- [ ] Data understanding
- [ ] Baseline
- [ ] Model selection
- [ ] Experiment design
- [ ] Evaluation
- [ ] Error analysis
- [ ] Iteration
- [ ] Final architecture
- [ ] Implementation
- [ ] Testing
- [ ] Documentation
- [ ] Limitations
- [ ] Future improvements

---

## The Final Success Criterion

> **You should be able to leave the final capstone and independently design and
> build a new AI/ML system that was never explicitly taught in the curriculum.**

That is the actual measure of success.
