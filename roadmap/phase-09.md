# Phase 09 — Generative AI

> **Goal:** Master generative AI — language models, inference, prompting, and LLM APIs.

**Prerequisites:** Phase 08
**Mastery target:** Level 5 (core concepts)

---

## Units

### Unit 09.1 — What Is a Language Model?
- Next-token prediction, probability of text
- **Implementation:** Explore a language model
- **Outcome:** Understand what an LLM is

### Unit 09.2 — Tokens & Tokenization
- Tokens, subwords, tokenizers
- **Implementation:** Tokenize text
- **Outcome:** Understand how text becomes numbers

### Unit 09.3 — Embeddings
- Dense vectors, semantic similarity
- **Implementation:** Explore embeddings
- **Outcome:** Understand semantic representation

### Unit 09.4 — Attention & Transformer Recap
- Self-attention, transformer recap
- **Implementation:** Review attention
- **Outcome:** Solidify the foundation

### Unit 09.5 — Pretraining
- How LLMs are trained on massive text
- **Implementation:** Understand pretraining objectives
- **Outcome:** Understand where LLMs come from

### Unit 09.6 — Inference & Decoding
- Greedy, beam search, sampling
- **Implementation:** Implement decoding strategies
- **Outcome:** Control generation

### Unit 09.7 — Temperature & Sampling
- Temperature, top-k, top-p
- **Implementation:** Experiment with sampling
- **Outcome:** Control creativity vs determinism

### Unit 09.8 — Instruction Following & Alignment
- Instruction tuning, RLHF, DPO
- **Implementation:** Understand alignment
- **Outcome:** Understand why models follow instructions

### Unit 09.9 — LLM APIs
- API keys, chat completion, streaming
- **Implementation:** Call an LLM API
- **Outcome:** Use LLM APIs

### Unit 09.10 — Prompt Engineering
- Clear instructions, few-shot, chain-of-thought
- **Implementation:** Engineer prompts
- **Outcome:** Get better outputs

### Unit 09.11 — Structured Output
- JSON mode, output parsers
- **Implementation:** Get structured output
- **Outcome:** Reliable structured data

### Unit 09.12 — Function/Tool Calling
- Tool definitions, function calling
- **Implementation:** Call tools
- **Outcome:** Foundation for agents

### Unit 09.13 — Streaming, Caching, Retries
- Streaming responses, caching, retries, rate limits
- **Implementation:** Robust API usage
- **Outcome:** Production-ready API calls

### Unit 09.14 — Generative AI Synthesis & Review
- Cumulative review
- Mini project: LLM application
- **Outcome:** Apply GenAI independently

At the end of this phase, you should be able to:

2. Tokenize and embed text.
3. Control generation with temperature/sampling.
4. Call LLM APIs robustly.
5. Engineer prompts effectively.
6. Get structured output and call tools.
