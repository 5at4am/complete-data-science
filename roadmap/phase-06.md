# Phase 06 — Deep Learning

> **Goal:** Master deep learning — from-scratch backpropagation through PyTorch and modern architectures.

**Prerequisites:** Phase 02, Phase 05
**Mastery target:** Level 5 (core concepts)

---

## Units

### Unit 06.1 — Perceptron & Activation Functions
- Neuron, activation (sigmoid, tanh, ReLU, softmax)
- **Implementation:** Perceptron from scratch
- **Outcome:** Understand the basic unit

### Unit 06.2 — Loss Functions
- MSE, cross-entropy, binary cross-entropy
- **Implementation:** Implement loss functions
- **Outcome:** Choose the right loss

### Unit 06.3 — Gradient Descent & Backpropagation (from scratch)
- Forward pass, chain rule, backward pass
- **Implementation:** Backprop from scratch in NumPy
- **Outcome:** Understand how networks learn

### Unit 06.4 — MLP with PyTorch
- Build a multi-layer network
- **Implementation:** PyTorch MLP
- **Outcome:** Use PyTorch effectively

### Unit 06.5 — Regularization
- L1/L2, dropout, batch norm, early stopping
- **Implementation:** Apply regularization
- **Outcome:** Prevent overfitting

### Unit 06.6 — Optimizers & Learning Rate Schedules
- SGD, momentum, Adam, AdamW
- LR schedules
- **Implementation:** Compare optimizers
- **Outcome:** Train efficiently

### Unit 06.7 — PyTorch Datasets & DataLoaders
- Dataset, DataLoader, transforms
- **Implementation:** Build data pipelines
- **Outcome:** Handle data in PyTorch

### Unit 06.8 — Training Loops & Validation
- Proper training/validation loops
- **Implementation:** Full training pipeline
- **Outcome:** Train models correctly

### Unit 06.9 — Checkpointing & Transfer Learning
- Save/load models, resume training
- Use pretrained models
- **Implementation:** Transfer learning
- **Outcome:** Leverage pretrained models

### Unit 06.10 — CNNs for Computer Vision
- Convolution, pooling, architecture
- **Implementation:** CNN in PyTorch
- **Outcome:** Image classification

### Unit 06.11 — RNNs, LSTMs, GRUs
- Sequence modeling, vanishing gradients
- **Implementation:** RNN/LSTM in PyTorch
- **Outcome:** Sequence data

### Unit 06.12 — Attention Mechanism
- Query, key, value, attention
- **Implementation:** Attention from scratch
- **Outcome:** Foundation for transformers

### Unit 06.13 — Deep Learning Synthesis & Review
- Cumulative review
- Mini project: train a neural model
- **Outcome:** Apply deep learning independently
