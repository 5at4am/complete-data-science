# ROADMAP

> **The complete dependency-aware learning progression.**
> This is not a list of technologies — it is a dependency-aware learning system.

---

## How to Use This Roadmap

1. Start at Phase 00.
2. Complete each unit in order.
3. Do NOT skip prerequisites.
4. Complete the phase review at the end of each phase.
5. Track progress in `tracking/progress.md`.
6. Record mistakes in `tracking/mistakes.md`.
7. Record experiments in `tracking/experiments.md`.

## Definition of "Complete"

The project is complete when:

- [ ] Roadmap exists
- [ ] Dependencies are mapped
- [ ] Notebooks are implemented
- [ ] Notebooks execute successfully
- [ ] Concepts are connected
- [ ] Mistakes are documented
- [ ] Reviews exist
- [ ] Projects exist
- [ ] Evaluation is included
- [ ] Engineering practices are included
- [ ] Security is included
- [ ] Deployment is included
- [ ] Capstones exist
- [ ] Progress is tracked
- [ ] Git history is maintained

**Most importantly:** the learner can leave the final capstone and independently
design and build a new AI/ML system never explicitly taught in the curriculum.
