# Experiment Log

> **Every meaningful experiment should be recorded.**
> This teaches scientific thinking instead of parameter guessing.

---

## How to Use

For every meaningful experiment, add an entry:

```text
### Experiment #N

- **Date:** YYYY-MM-DD
- **Unit:** e.g., 05.2 Linear Regression
- **Hypothesis:** What do I expect to happen?
- **Setup:** What did I do?
- **Variables:** What did I change?
- **Expected result:** What did I predict?
- **Actual result:** What actually happened?
- **Observation:** What did I notice?
- **Interpretation:** What does this mean?
- **What changed my understanding?** How did this change my thinking?
- **Next experiment:** What should I try next?
```

## Suggested Experiments (from the curriculum)

### Linear Regression

### Gradient Boosting
- Random Forest vs XGBoost

- Effect of learning rate
- Effect of batch size
- Effect of dropout rate
- Optimizer comparison (SGD vs Adam)

### RAG
- Chunk size effect
- Embedding model comparison
- Hybrid vs vector-only search
- Reranking effect

### Agents
- Tool selection accuracy
- Loop termination
- Cost per task
