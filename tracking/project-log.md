# Project Log

> **Track all projects and their outcomes.**
> Projects increase in independence as you progress.

---

## Project Levels

- **Level 1 — Guided:** Everything is specified.
- **Level 2 — Partially guided:** Dataset and objective provided, decisions left to learner.
- **Level 3 — Open-ended:** Only problem statement provided.
- **Level 4 — Engineering challenge:** Requirements + constraints + evaluation.
- **Level 5 — Production-style capstone:** Full system design.

---

## How to Use

For every project, add an entry:

```text
### Project #N

- **Date:** YYYY-MM-DD
- **Name:** Project name
- **Level:** 1-5
- **Phase:** Which phase does it belong to?
- **Problem:** What problem does it solve?
- **Approach:** What did I build?
- **Result:** What was the outcome?
- **What I learned:** Key takeaways
- **What I'd improve:** Future improvements
- **Status:** Complete / In progress / Blocked
```
