# Prerequisites

> **What you need before starting this learning system.**

---

## Hard Requirements

### 1. Basic Computer Skills
- Navigate files and folders
- Install software
- Use a text editor or IDE

### 2. Python Fundamentals (Level: comfortable beginner)
You should be able to:
- Write and run a Python script
- Use variables, data types, lists, dicts, loops, conditionals
- Define and call functions
- Understand basic control flow

> **Note:** If you are not yet comfortable with Python, start with Phase 01
> (Python Foundations) which covers everything from the ground up.

### 3. A Working Environment
- Python 3.13+ installed
- A package manager (uv, pip, conda)
- Jupyter Notebook or JupyterLab
- Git installed

### 4. Internet Access (recommended)
- For installing packages
- For downloading datasets
- For accessing LLM APIs (optional)

---

## Recommended (Not Required)

### Mathematics
- High-school algebra (variables, equations, functions)
- Basic probability and statistics intuition

> **Do not worry if your math is rusty.** The curriculum teaches mathematics
> when it becomes useful, with implementation-first examples.

### Hardware
- A modern CPU (required)
- A GPU (recommended for deep learning, but NOT required — CPU works for learning)

---

## What You Do NOT Need

- A paid API key (local alternatives are provided)
- A GPU (CPU-only works for the entire curriculum)
- Prior ML/AI experience (the curriculum starts from zero)
- A degree in mathematics or computer science

---

## Time Commitment

This is a **deep, implementation-first** curriculum. It is not a speed-run.

- Each unit takes meaningful effort (implementation + experiments + review).
- Progress is measured by **understanding**, not by notebook count.
- You should expect to spend significant time on each phase.

---

## Mindset

- **Curiosity** — ask "why" constantly
- **Persistence** — debugging is part of learning
- **Honesty** — record your mistakes, don't hide them
- **Patience** — depth beats speed
